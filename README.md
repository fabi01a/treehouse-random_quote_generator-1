# Random Quote Generator

## Project Overview

Random Quote Generator is an interactive web application built with vanilla JavaScript that displays inspirational and motivational quotes from a collection of notable figures.

Users can generate a new quote with the click of a button, while the application automatically refreshes the displayed quote every 10 seconds. Each new quote also triggers a randomly generated background color, creating a dynamic and engaging experience.

This project was developed as part of the Treehouse Full Stack JavaScript Techdegree program.

## Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Styling and visual presentation
- **JavaScript (ES6)** – Application logic, randomization, and DOM manipulation

## Key Features

- Randomly selects quotes from an array of 10 quote objects
- Displays the quote and its author, along with optional citations, publication years, and tags
- Generates a random background color whenever a new quote appears
- Automatically displays a new quote every 10 seconds using `setInterval()`
- Allows users to manually generate quotes with a button click
- Dynamically updates page content without requiring a refresh
